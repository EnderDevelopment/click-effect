# Inventory Effects Mod

The Inventory Effects Mod is a Minecraft mod designed to enhance the user experience by adding visual effects when interacting with inventories, options, and menus. This mod is compatible with Minecraft 1.8.9 and Forge 1.8.9, ensuring seamless integration with existing setups. It is ideal for players who enjoy visual feedback and want to make their gameplay more engaging.

## Install

1. Download the mod jar file from the GitHub repository.
2. Place the jar file in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with Forge installed.

## Use

1. Launch Minecraft with the mod installed.
2. Interact with inventories, options, and menus to see the visual effects.
